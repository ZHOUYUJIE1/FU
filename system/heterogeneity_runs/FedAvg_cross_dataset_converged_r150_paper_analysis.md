# Cross-Dataset Paper Analysis

## Key observations

### STL-10
- Best utility: `FedCSA` with `final_avg_acc=0.3412`.
- Strongest forgetting: `Retrain` with `final_target_acc=0.0030`.
- FU achieves `final_avg_acc=0.3377` and `final_target_acc=0.0788`.

### Tiny-ImageNet
- Best utility: `FedAU` with `final_avg_acc=0.1682`.
- Strongest forgetting: `Retrain` with `final_target_acc=0.0000`.
- FU achieves `final_avg_acc=0.1369` and `final_target_acc=0.0110`.
